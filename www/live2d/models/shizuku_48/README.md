This folder is a Live2D v2 development sample copied from the local
`live2d_demo` reference for dancer playback testing.

It is used as a newer default test model because it has visible v2 motion
parameters such as `PARAM_ANGLE_*`, `PARAM_BODY_*`, `PARAM_ARM_*`, and
`PARAM_BASE_*`.
